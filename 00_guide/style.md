# 스타일 가이드 — 확률과 통계 (공대 1학년)

## 말투: 명사 종결
- 모든 bullet과 제목은 명사로 끝맺음
- "~다", "~요", "~니다"로 끝나는 서술형 문장 금지

| 피할 표현 | 쓸 표현 |
|---|---|
| 두 사건이 독립이면 곱셈법칙이 성립한다 | 독립 사건에서의 곱셈법칙 성립 |
| 분산은 퍼진 정도를 나타냅니다 | 분산: 자료의 퍼진 정도의 척도 |
| 표본평균은 정규분포를 따른다 | 표본평균의 정규분포 근사 |

- 정의는 "용어: 설명" 형식 (예: "확률변수: 표본공간에서 실수로의 함수")

## 그림 중심 구성
- 슬라이드마다 그림/도표/그래프 최소 1개
- 개념마다 시각화 우선
  - 사건과 집합 → 벤 다이어그램
  - 조건부 확률, 베이즈 정리 → 트리 다이어그램, 넓이 비율 그림
  - 확률분포 → PMF 막대그래프, PDF/CDF 곡선
  - 기댓값, 분산 → 분포 위 중심과 퍼짐 표시
  - 중심극한정리 → 표본 크기별 히스토그램 비교
  - 추정, 검정 → 신뢰구간 막대, 기각역 음영
- 수식은 그림 옆에 배치하고, 수식만 있는 슬라이드는 피함
- 텍스트는 그림 설명을 보조하는 수준으로 최소화

## 슬라이드 구성
- 표지 → 학습목표 → 공학 예시로 동기 부여 → 본문 → 예제 풀이 → 요약 → 확인 문제 → 다음 시간 예고
- 슬라이드당 bullet: 최대 4개, 한 줄 30자 이내
- 슬라이드 장수: (예: 차시당 20~25장)

## 공학 예시 소재
- 부품 불량률, 품질관리
- 시스템 신뢰성(직렬/병렬 회로)
- 센서 측정 오차, 신호 잡음
- 통신 비트 오류, 대기열(포아송)
